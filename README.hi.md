## सुविधाएँ

- वास्तविक VRAM का उपयोग और खाली स्थान, GPU उपयोग तथा तापमान, साथ में छोटे इतिहास ग्राफ़।
- GPU मेमोरी उपयोग करने वाले स्थानीय ऐप और सेवाएँ; खोज, क्रमबद्ध करना और 0.5 GiB से अधिक उपयोग का वैकल्पिक फ़िल्टर।
- पिछले 30 दिनों के देखे गए नमूनों से शीर्ष 10 ऐप और “अन्य” के सामान्यीकृत हिस्से। कुल 100% होता है; यह दर्ज प्रक्रिया-मेमोरी रीडिंग का ऐतिहासिक वितरण है, वास्तविक VRAM के जोड़ने योग्य अलग हिस्सों का मापन नहीं।
- पिछले 24 घंटों में वैध निगरानी समय का वह प्रतिशत जब वास्तविक VRAM उपयोग 50% से ऊपर था। निगरानी के अंतराल गणना से बाहर रहते हैं।
- चुने हुए स्थानीय स्थान पर UTF-8 CSV निर्यात। सिस्टम ट्रे में छोटा करना, दोबारा शुरू करने पर मौजूदा विंडो लौटाना और वैकल्पिक Windows स्टार्टअप।
- सिस्टम और गहरे Graphite रूप, 12 इंटरफ़ेस भाषाएँ और 1–5 सेकंड का अपडेट अंतराल; डिफ़ॉल्ट 2 सेकंड।
- समर्थित पावर और कोर-क्लॉक सीमाओं से 70–88°C का नरम तापमान लक्ष्य; नियंत्रण UI अपडेट से स्वतंत्र चलता है। निष्क्रिय अवस्था में कूलिंग, वास्तविक RPM संकेतक और घूमते पंखे के चिह्न उपलब्ध हैं।
- नए प्रोफ़ाइल में तापमान नियंत्रण और idle cooling चालू करने की इच्छा सक्षम होती है। पहले से सहेजा गया मैनुअल OFF सुरक्षित रहता है। पुष्टि किए गए कनेक्शन के बाद ही नियंत्रण सक्रिय दिखता है।
- वैकल्पिक चेतावनी: तापमान चुनी हुई 75–92°C सीमा से लगातार कम से कम 10 सेकंड सख्ती से ऊपर रहे। छोटी बढ़त चेतावनी नहीं बनाती।
- पहले से चुने ऐप के लिए अलग आपातकालीन विकल्प, जो डिफ़ॉल्ट रूप से बंद है। सुरक्षित या अप्रमाणित प्रक्रियाएँ इस कार्रवाई के लिए नहीं चुनी जा सकतीं।

## चार त्वरित कार्रवाई बटन

चार छोटे बटनों में “ऐप बंद करें” या “प्रक्रिया समाप्त करें” निर्धारित करें; पास के `⋮` मेनू से बदलें। हर बंधन स्पष्ट रूप से चुने उसी process instance के PID, निर्माण समय और EXE पथ से जुड़ा है। उसके समाप्त होने पर पास की प्रक्रिया, नया instance या दोबारा इस्तेमाल हुआ PID अपने-आप नहीं चुना जाता।

निर्धारित बटन **अतिरिक्त पुष्टि के बिना एक क्लिक में** काम करता है। ऐप बंद या प्रक्रिया समाप्त करने से बिना सहेजा काम खो सकता है। महत्वपूर्ण, सुरक्षित और अप्रमाणित प्रक्रियाओं की native जाँच बनी रहती है। अलग आपातकालीन विकल्प पहले की तरह चुने ऐप पर लागू होता है और शुरुआत में बंद रहता है।

## तापमान लक्ष्य और हिस्टेरिसिस

| सेटिंग | वास्तविक व्यवहार | कारण |
|---|---|---|
| Idle लक्ष्य: डिफ़ॉल्ट 32°C, बदलने योग्य 28–40°C | Idle में लक्ष्य या उससे नीचे 3 सेकंड रहने पर पंखे का नियंत्रण फ़र्मवेयर AUTO को लौटता है। कूलिंग लक्ष्य +4°C पर लौटती है: 32°C के लिए 36°C, 35°C के लिए 39°C। | एक सीमा के आसपास बार-बार चालू/बंद होने से बचाव। AUTO में पूरी तरह पंखा रोकना फ़र्मवेयर तय करता है। |
| Idle और लोड की पहचान | GPU उपयोग 10% तक idle स्वीकार्य है; 15% से लोड कूलिंग लागू होती है। 11–14% में पिछली अवस्था बनी रहती है। अज्ञात उपयोग कूलिंग को चालू रखता है। | छोटे बदलावों से अवस्था बार-बार न बदले। |
| नरम लक्ष्य 70–88°C | तापमान के रुझान से पावर और कोर-क्लॉक सीमा धीरे बदलती है। वास्तविक तापमान लक्ष्य से कम या थोड़े समय के लिए अधिक हो सकता है। | लक्ष्य आपातकालीन कठोर कटऑफ़ नहीं; तापीय जड़ता, सेंसर और ड्राइवर सीमाएँ असर डालते हैं। |
| अधिक तापमान की चेतावनी | चुनी सीमा से लगातार कम से कम 10 सेकंड ऊपर होना चाहिए। | क्षणिक उछाल को अनदेखा करना। |

Idle तापमान लगातार लोड का तापमान-सीमा नहीं है। परिवेश, बोर्ड फ़र्मवेयर और ड्राइवर से उपलब्ध परिणाम बदलते हैं। एक ही कार्ड पर विरोधी पंखा, पावर या क्लॉक नियंत्रक साथ न चलाएँ।

## हार्डवेयर और आवश्यकताएँ

NVIDIA GeForce **RTX 5000 Series** के लिए। निगरानी और उपलब्ध नियंत्रण कार्ड तथा ड्राइवर पर निर्भर हैं; असमर्थित नियंत्रण का अनुकरण नहीं किया जाता।

Windows 10/11 x64, .NET Framework 4.8 और समर्थित NVIDIA ड्राइवर आवश्यक हैं। Java runtime इंस्टॉलर में है; अलग Java स्थापित करने की आवश्यकता नहीं। ड्राइवर संस्करण या DLL hash की मैनुअल allowlist नहीं है। स्थापित सिस्टम NVML को सुरक्षित पथ, ऑफ़लाइन Windows हस्ताक्षर, सत्यापित NVIDIA Corporation signer और आवश्यक API की जाँच पास करनी चाहिए। ड्राइवर अपडेट पर नया संस्करण या hash जोड़ना आवश्यक नहीं। स्थानीय trust data न मिलने पर सत्यापन विफल हो सकता है; ऐप प्रमाणपत्र या ड्राइवर डाउनलोड नहीं करता।

साइन-इन Windows उपयोगकर्ता को सामान्य सीमित desktop token वाला administrator होना चाहिए। इंस्टॉलर एक बार UAC माँगता है और निश्चित, सुरक्षित Program Files फ़ोल्डर में नियंत्रण घटक स्थापित करता है। किसी दूसरे administrator की credentials देना समर्थित नहीं है। दो सुरक्षित demand-only tasks निश्चित launchers और typed local communication इस्तेमाल करते हैं। स्थापित चैनल आगे नियंत्रण चालू करने पर नया UAC न माँगने के लिए बनाया गया है; घटक प्रमाणित न हो तो नियंत्रण अनुपलब्ध रहता है, किसी दूसरे elevation prompt पर नहीं जाता।

## स्थापना और गोपनीयता

1. इंस्टॉलर डाउनलोड कर उसका SHA-256 [SHA256SUMS.txt](SHA256SUMS.txt) से मिलाएँ।
2. पुरानी प्रति को ट्रे के “Exit” से बंद करें। साइन-इन administrator से इंस्टॉलर सामान्य रूप से शुरू कर UAC स्वीकारें। सुरक्षित स्थापना फ़ोल्डर निश्चित है।
3. नया शॉर्टकट खोलें, GPU चुनें और नियंत्रक की पुष्टि की गई स्थिति देखें। नियंत्रण तथा त्वरित बटन अपनी आवश्यकता के अनुसार सेट करें। सेटिंग स्थानीय रहती हैं और सहेजा मैनुअल OFF बना रहता है।

ऐप स्थानीय Windows/GPU इंटरफ़ेस उपयोग करता है। इसमें नियोजित telemetry upload, cloud inference, self-update या चलते समय model download नहीं है। CSV, इतिहास और सेटिंग स्थानीय रहते हैं। यह पूरी OS नेटवर्क अलगाव या तृतीय-पक्ष ड्राइवर, Windows diagnostics और sync software के व्यवहार की गारंटी नहीं है।

इंस्टॉलर व्यक्तिगत publisher certificate से signed नहीं है। केवल compiled binaries वितरित होते हैं; **ऐप का source code इस repository में प्रकाशित नहीं होता**। Java bytecode encrypted नहीं है और decompilation रोकने की गारंटी नहीं दी जाती। तृतीय-पक्ष runtime के license notices स्थापित runtime में सुरक्षित हैं।

स्क्रीनशॉट में कृत्रिम demo data और simulated controller state है; वे निजी ऐप सूची या वास्तविक तापीय प्रदर्शन का प्रमाण नहीं हैं।

## 1.10 में बदलाव और सत्यापन

चार assignable बटन जोड़े गए, कार्ड के विवरण का फ़ॉन्ट छोटा किया गया और mini-graphs की ऊँचाई 35 से 55 pixels हुई; स्पष्ट ट्रे आइकन बना है। सुरक्षित नियंत्रण घटक एक बार UAC के साथ स्थापित होता है। केवल पुष्टि किए गए non-render IDD aliases हटाए जाते हैं; अलग वास्तविक GPU केवल नाम या memory bytes के आधार पर नहीं मिलाए जाते। सुरक्षित अधूरी स्थापना सुधारी जा सकती है; विफलता में स्पष्ट phase, code और HRESULT मिलता है। दो themes, 12 भाषाएँ, स्थानीय इतिहास, UTF-8 CSV, GPU identity checks और lease/watchdog/restore नीति सुरक्षित हैं।

12 भाषाओं और दो themes के 48 isolated UI cases, icons, default settings, quick-action binding/runner, वास्तविक CLR token checks, Unicode पथ, सभी 163 package files और pinned broker hashes तथा isolated install/uninstall जाँचे गए। वास्तविक elevated temporary Scheduler test ने दोनों definitions register कीं, XML/DACL पढ़े, rollback जाँचा और अपने tasks/folder हटाए। **Tasks चलाए नहीं गए**; उस टेस्ट ने GPU setters या production tasks नहीं चलाए।

यह registration fixture पूर्ण production-installer workflow या उसके बाद बिना UAC वास्तविक GPU actuation का प्रमाण नहीं है। लगातार भारी लोड में तापीय प्रदर्शन इन जाँचों से प्रमाणित नहीं होता।
