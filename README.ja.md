**Windows x64 向けのローカル GPU メモリ監視・温度制御ツールです。**

[Windows インストーラー](downloads/VRAM-GPU-Desk-1.10-Setup-x64.exe) · [インストーラー ZIP](downloads/VRAM-GPU-Desk-1.10-Installer.zip)

> **GPU 制御:** GPU の温度パラメーターを制御するには、制御コンポーネントのインストール時に一度 UAC の確認が必要です。その後、温度制御や冷却を有効にするときに UAC の再確認はありません。監視機能だけなら UAC は不要です。

> **GPU の同時制御:** GPU の温度パラメーター制御は、電力、クロック、ファン速度を同時に変更する他のプログラム（MSI Afterburner など）と競合する場合があります。これらの設定を操作する有効な制御ソフトは一つだけにしてください。この注意は設定の同時変更に関するもので、受動的な監視は対象ではありません。

## 機能

- 物理 VRAM の使用量と空き容量、GPU 使用率、温度を小さな履歴グラフとともに表示します。
- GPU メモリを使用するローカルのアプリとサービスを一覧表示し、検索、並べ替え、任意の **0.5 GiB 超**フィルターを提供します。
- 過去 30 日間に観測したサンプルから、上位 10 アプリと「その他」の正規化された割合を表示します。合計は 100% です。これは記録されたプロセスメモリ値の履歴上の配分であり、足し合わせて物理 VRAM 全体になる実際の領域分割ではありません。
- 過去 24 時間の有効な観測時間のうち、物理 VRAM 使用率が 50% を超えた時間の割合を表示します。監視の空白時間は除外します。
- 選択したローカルパスへ UTF-8 CSV レポートを保存します。
- システムトレイへの最小化、再起動時の既存ウィンドウ復元、任意の Windows 起動時実行を提供します。
- システムテーマと暗いグラファイトテーマ、12 言語に対応します。UI 更新間隔は 1–5 秒、既定値は 2 秒です。
- 対応する電力・コアクロック制限を通じ、任意の GPU 温度ソフト目標制御を提供します。制御は UI 更新間隔とは独立して動作します。
- アイドル冷却、ファン RPM 表示、動くファンアイコンを提供します。新しい設定では温度制御とアイドル冷却の両方をオンにするよう要求し、保存済みの手動 OFF は維持します。接続が確認された後にのみ制御の有効状態を表示します。
- 選択した 75–92°C のしきい値を厳密に上回る状態が 10 秒以上続いたときに警告できます。短い温度上昇では警告しません。
- 明示的に選択したアプリに対する独立した緊急オプションを備え、既定ではオフです。アプリを閉じたりプロセスを終了したりすると未保存の作業が失われる可能性があります。保護対象または検証できないプロセスは、この操作の対象に選べません。

## 4 つのクイック操作ボタン

4 つのコンパクトなボタンに **アプリを閉じる**または**プロセスを終了する**を割り当て、隣の `⋮` メニューから再割り当てできます。各割り当ては、PID、作成時刻、実行ファイルのパスで識別した、明示的に選択されたプロセスインスタンスに対応します。そのインスタンスが終了しても、別のプロセスや同じ PID を再利用したプロセスが自動選択されることはありません。

設定済みボタンは 1 回のクリックで、**追加確認なしに実行**します。閉じる操作や終了操作により、未保存の作業が失われる可能性があります。保護対象、重要、または検証できないプロセスに対するネイティブ検査は維持されます。独立した緊急オプションは既定でオフのままで、選択アプリに対する従来の動作を維持します。

## 温度目標とヒステリシス

一部の設定は、停止と再開に異なるしきい値と短い待機時間を意図的に使います。測定値が数度変動するときの頻繁な切り替えを防ぎます。

| 設定 | 実際の動作 | 理由 |
|---|---|---|
| アイドル目標は既定 **32°C**、28–40°C で調整可能 | アイドル時、32°C 以下が 3 秒続くと、制御をカードのファームウェア AUTO に戻します。目標 +4°C の 36°C で冷却を再開します。目標 35°C の場合は 39°C で再開します。 | 4°C のヒステリシスで、単一のしきい値付近でファンが始動・停止を繰り返すのを防ぎます。完全停止するかどうかは、アプリではなくファームウェア AUTO が決めます。 |
| アイドル／負荷の判定 | GPU 使用率 10% 以下ではアイドル動作を許可し、15% 以上では負荷時の冷却曲線を使います。11–14% では直前の判定を保持します。使用率が不明な場合も冷却を続けます。 | 小さな使用率変動でモードが頻繁に切り替わるのを防ぎます。 |
| 温度ソフト目標 70–88°C | 温度上昇の傾向を考慮し、目標付近の動作帯域で電力・コアクロック制限を徐々に調整します。実際の温度が目標より低くなる場合や、一時的に超える場合があります。 | 熱慣性、センサー更新、ドライバーの制限により、正確な強制上限は保証できません。これは制御の目安であり、緊急遮断のしきい値ではありません。 |
| 過熱警告 | 測定値がしきい値を厳密に上回る状態が最低 10 秒続く必要があります。 | 短い温度上昇による警告を抑えます。 |

アイドル温度は、継続的な負荷時の温度上限では**ありません**。到達可能な温度やファンの応答は、周囲環境、カードのファームウェア、ドライバー制限によって変わります。同じカードに対して競合するファン・クロック制御ソフトを同時に使用しないでください。

## ハードウェアと動作要件

NVIDIA GeForce **RTX 5000 Series** GPU 向けです。監視機能と利用可能な制御は GPU とドライバーに依存します。未対応の制御を動作しているように模擬することはなく、利用不可のままにします。

Windows 10/11 x64、.NET Framework 4.8、対応する NVIDIA ドライバーが必要です。インストーラーには Java ランタイムが含まれ、別途 Java を入れる必要はありません。Windows にサインイン中のユーザーが管理者であり、通常の制限されたデスクトップトークンを使っている必要があります。セットアップは UAC を 1 回要求し、固定された保護済み Program Files ディレクトリに制御コンポーネントを設置します。別の管理者の資格情報を入力する方式には対応しません。

保護された 2 つのタスクは要求時にのみ起動し、固定の制御ランチャーと型付きのローカル通信を使います。インストール後の経路は、追加 UAC なしで制御を開始できるよう設計されています。認証できない場合は別の昇格要求に切り替えず、制御を利用不可にします。

ドライバーのバージョンや DLL ハッシュの許可リストは使いません。システムに導入された NVML ライブラリは、確認済みの NVIDIA Corporation 署名者によるオフライン Windows 署名検証、安全なパスの検査、必要 API の検査に通る必要があります。ドライバー更新時に新しいバージョンやハッシュを追加する必要はありません。必要な信頼情報がローカルにないと、オフライン検証が失敗する場合があります。アプリは証明書やドライバーをダウンロードしません。

## インストールとプライバシー

1. インストーラーをダウンロードし、[SHA256SUMS.txt](SHA256SUMS.txt) と SHA-256 を照合します。
2. 旧バージョンをトレイメニューから終了します。サインイン中の管理者アカウントでセットアップを通常起動し、UAC を承認します。保護されたインストール先は固定です。
3. 新しい VRAM GPU Desk のショートカットを開き、GPU を選択して、確認済みの制御状態を確認します。必要に応じて制御とクイックボタンを設定します。設定はローカルに保存され、保存済み OFF は OFF のままです。

アプリはローカル Windows/GPU インターフェースを使います。設計上のテレメトリー送信、クラウド推論、自動更新、実行中のモデルダウンロードはありません。CSV、履歴、設定はローカルに残ります。これは OS 全体のネットワーク隔離や、サードパーティードライバー、Windows 診断、同期ソフトの動作を保証するものでは**ありません**。

インストーラーは未署名です。コンパイル済みのバイナリとして配布し、**このリポジトリではアプリのソースコードを公開しません**。Java バイトコードは暗号化されておらず、逆コンパイルできないことも保証しません。サードパーティーランタイムのライセンス表記は、インストールされたランタイム内に保持します。

スクリーンショットは合成デモデータと模擬した制御状態を使います。インターフェースの例であり、ハードウェア制御の動作や性能を証明するものではありません。

## 1.10 の変更点

- 特定のプロセスインスタンスに結び付く、設定可能な 4 つのクイックボタンを追加しました。1 回のクリックで閉じる／終了を実行し、再割り当てと既存のネイティブ安全検査に対応します。
- ダッシュボードの説明文字を小さくし、ミニグラフの高さを 35 ピクセルから 55 ピクセルに増やしました。高コントラストのトレイアイコンは維持しています。
- 保護された制御コンポーネントを 1 回の UAC で設置します。新しい温度・アイドル冷却設定はオンで、保存済みの手動 OFF は保持します。
- 保守的なアダプター別名修正を含みます。レンダリングを行わないと確認された間接ディスプレイの別名だけを除外し、名前やメモリ値で別の物理 GPU を統合しません。
- 安全な未完了インストールを修復し、コンポーネントのセットアップ失敗時には具体的な段階、コード、HRESULT を報告します。
- 2 つのテーマ、12 言語、ローカル履歴、UTF-8 CSV、GPU 識別検査、既存の lease/watchdog/restore 方針を維持します。

このリリースでは、12 言語と 2 テーマによる 48 件の隔離 UI ケース、トレイアイコン、既定設定、クイック操作の割り当てと実行器、実際の CLR トークン検査、Unicode パス、全 163 パッケージファイルと埋め込みブローカーハッシュ、隔離インストール／アンインストールを確認しました。実際に昇格した一時タスクスケジューラー登録テストでは、XML/DACL の読み戻し、ロールバック、後片付けを確認しました。一時タスクは**実行しておらず**、このテストで GPU 設定操作や本番タスクを呼び出していません。

この登録テストは、本番インストーラー全体の実行と、その後の UAC なしの GPU ハードウェア操作を検証したものではありません。継続負荷での温度制御性能も証明していません。スクリーンショットは合成データと模擬した制御状態を示しています。
